# PULSE click samples

CC0 1.0, source files below. The included 32 kHz mono PCM16 WAVs are prepared from these recordings: onset trimmed, DC removed, short fade, RMS/peak limited. Accent/beat/subdivision playback uses scaled copies of the same source. `src/click-samples.ts` embeds the identical PCM for synchronous playback. No oscillator is used for these six sounds.

- **woodblock**: [Idiophones/Struck Idiophones/Woodblock/wood_click_mp.wav](https://github.com/sgossner/VCSL/blob/master/Idiophones/Struck%20Idiophones/Woodblock/wood_click_mp.wav), source blob `f625cb9b072b8a88ad588f8c125654f31e8c36cb`, CC0-1.0.
- **studioStick**: [Membranophones/Struck Membranophones/Snare Drum, Modern 3/Snare4_Xstick_v2_rr1_Mid.wav](https://github.com/sgossner/VCSL/blob/master/Membranophones/Struck%20Membranophones/Snare%20Drum%2C%20Modern%203/Snare4_Xstick_v2_rr1_Mid.wav), source blob `f113b6d61a119d333c986e00ab536926898ef4a6`, CC0-1.0.
- **rimshot**: [Membranophones/Struck Membranophones/Legacy Snares/drum1/snare1_rimshot_mf.wav](https://github.com/sgossner/VCSL/blob/master/Membranophones/Struck%20Membranophones/Legacy%20Snares/drum1/snare1_rimshot_mf.wav), source blob `7c2b955e9fa98c9ccd23de9008c6e23fc68bdf1f`, CC0-1.0.
- **claves**: [Idiophones/Struck Idiophones/Claves/Legacy/claves_pp1.wav](https://github.com/sgossner/VCSL/blob/master/Idiophones/Struck%20Idiophones/Claves/Legacy/claves_pp1.wav), source blob `63f9c85195facb28439f73ab634a6cc4794c79ad`, CC0-1.0.
- **softBlock**: [Idiophones/Struck Idiophones/Woodblock/wood_click_pp_rr3.wav](https://github.com/sgossner/VCSL/blob/master/Idiophones/Struck%20Idiophones/Woodblock/wood_click_pp_rr3.wav), source blob `63e544917f0dd25f9bd70314f57750243d506303`, CC0-1.0.
- **electronic**: [samples/percs/tick-01.wav](https://github.com/octalmusic/octal-samples/blob/main/samples/percs/tick-01.wav), source blob `3360f55cd5d33b924fe10c30f9af88866ce3798b`, CC0-1.0.

The electronic tick is a prepared electronic one-shot, not a recording of a mechanical metronome. Claves is an acoustic alternative.
